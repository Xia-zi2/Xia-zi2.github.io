# 为什么把学术主页与研究笔记放在一起

传统个人主页适合快速介绍“我是谁”，文档站适合回答“我具体做了什么、如何做到”，Blog 则适合呈现经过整理的观点。本站把三者放在同一个静态站点中，但保留清晰边界：

- **项目**整理目标、方法、实现与可展示结果；
- **Notes**保留论文阅读、复现过程和技术细节；
- **Blog**把已经形成结构的内容重新写成完整文章。

这种组织方式的核心不是页面数量，而是维护路径足够短：新建 Markdown、填写 front matter、提交并推送。首页、搜索、标签和 Blog 归档都由构建流程更新。
