# 论文阅读

每篇笔记可按需填写 `authors`、`venue`、`year`、`paper`、`code`、`project`、`tags`、`date` 和 `status`。不要求所有字段完整，值为 `TODO` 的字段不会出现在页面元数据卡片中。

## 分类

- Computer Graphics
- 3D Vision
- Dexterous Hand
- RAG
- LLM / Agent
